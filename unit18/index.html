UNIT 18 · MULTIMODAL JAILBREAKS

The jailbreak is in the picture.

Vision-language models read text inside images. So hide the instruction there.

HOOK30 SEC
EXPLORABLE6 MIN

Two panels. Hide the instruction, then push it until it breaks.

A · Typographic attack

type an instruction, then toggle the layer

A plain photo. Burn a sentence into it as a sticky note, then ask a simulated vision model what it sees. Toggle the note on and off — the pixels of the scene never change.

SIMULATED VLM SAYS →
CAPTION, NOT A COMMAND With the layer off, the model just describes the scene. Nothing in the pixels asked it to do anything else.

B · Adversarial pixels

simulated — real attacks need gradients, not a slider

No text anywhere this time. Same sign, same pixels wearing a small, structured noise. Drag the slider up and watch the label a vision model reports — illustrative only, see the honest label below.
